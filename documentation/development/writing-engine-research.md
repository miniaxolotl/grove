# Pilot plain LanguageTool, keep proofreading local-first

**Keep Grove’s local checker and trial plain LanguageTool (LT) 6.8 only as an explicitly requested second opinion.** Run it as a private DigitalOcean App Platform service behind the existing Grove API; budget **+$49/month** for one warm instance, before accepting any production capacity claim. On 60 synthetic English fixtures, plain LT added **seven correct diagnoses and one new false alarm** beyond on-device Harper. The full English n-gram index changed **nothing on those 60**, although it corrected a real-word confusion in a separate control. The next investment should be testing the _actual rules and merge policy_ on held-out notes, not buying storage for the index or building a new gateway. Findings below are from local tests and published terms reviewed **18 November 2026**; no cloud trial, implementation or deployment occurred.

## Seven useful diagnoses depend on what the editor shows

The comparison used 12 owner-supplied errors, six owner clean controls, 20 developer/meeting-note fixtures and 22 other sentences. Gold spans and intended edits were specified before execution. Each row was checked independently; a hit required the intended diagnosis on the target, not simply an underline somewhere in the sentence. “First edit” means substituting the first suggestion repaired the entire sentence. Unwanted suggestions count even on _positive_ rows. These are deliberately difficult cases, not population accuracy estimates.

**The union is 31/40, not 30/40:** Harper alone fixed “longer then the draft.” LT’s one new false alarm, `PREPOSITION_VERB`, changed team shorthand “deploy notes” to “deployment notes” while missing the actual “notes was” error. Both engines flagged `befor` at UTF-16 **[28,33)**; Harper offered only `be for`. Dropping every overlapping LT finding therefore yields **+6**, versus **+7** if the editor preserves the alternative diagnosis. Compared with _Grove plus Harper_ (26/40), LT adds five unique targets; Grove already caught `befor` and “between you and I.” The conservative rule profile below includes only the dictionary ID among these seven: **do not ascribe the default-engine gain to the proposed allowlist**. Admit the other six individually or define an enhanced grammar group and rescore the merged output.

LT and Harper both fixed “You're car,” “the dog wagged it's tail,” “I have went” and “the affect of the change.” Neither fixed “Your welcome to join us,” “There going,” “Its raining,” “Each of the students have” or “Then end.” LT’s partial “Me and him went” → “I and him went” earned no hit. On the six owner clean controls LT abstained throughout; Grove changed `are`, `work`, `use to` in valid contexts, while Harper simplified grammatical `had had` and changed mandative `go` to `goes`. On six additional wrong/right homophone pairs, plain LT caught five errors; **only the indexed JVM** corrected “You need to **brake** the habit” to `break` (`CONFUSION_RULE_BRAKE_BREAK`, [12,17)). Both spared all six correct counterparts. This verifies model activity without moving the 60-fixture denominator ([upstream n-gram mechanism](https://dev.languagetool.org/finding-errors-using-n-gram-data)).

**Reproduce the comparison:** use [Grove at `a47f1d4`](https://github.com/miniaxolotl/grove/tree/a47f1d443441fdbb06d385f56be601d518add762), Node 24.21.0, pnpm 10.33.0, frozen dependencies, default settings, empty personal dictionary and the real extension checker, requesting spelling alternatives on demand (23/23 native writing tests passed). Feed Harper’s full `LocalLinter` with its default Markdown parser and both LT servers the exact output of Grove’s [`prose()`](https://github.com/miniaxolotl/grove/blob/a47f1d443441fdbb06d385f56be601d518add762/lib/shared/src/writing-settings.ts); POST `language=en-US&text=…`, reject incomplete checks. Compare original and masked slices before applying each candidate. A link retained its misspelled label while its hidden destination became artificial whitespace; masking `load_test` also removed agreement context. LT and Harper JS both found `enviroment` at **[24,34)** after emoji, CJK and inline code. Preserving UTF-16 length preserves coordinates, not grammar or confidentiality.

## A warm paragraph check fits better than a cold document check

**Local LT recipe.** Use the [Maven Central 6.8 standalone ZIP](https://repo.maven.apache.org/maven2/org/languagetool/languagetool-standalone/6.8/) rather than the unversioned website ZIP (contained 6.6). The 258,509,167-byte archive matched Central SHA-256 `f04aecf37e35ef17d44b336da9668a5a3a871edd14bd83a766a7e110b9ebcd21`. The [full English ZIP](https://languagetool.org/download/ngram-data/ngrams-en-20150817.zip) was 8,961,853,713 bytes and expanded to **15,401,820,145 bytes**; locally computed SHA-256 `10e548731d9f58189fc36a553f7f685703be30da0d9bb42d1f7b5bf5f8bb232c` is a repeatability pin, not a publisher signature. Mount `en/{1grams,2grams,3grams}` read-only on SSD and pass the **parent of `en`** as `--languageModel` only for the indexed run.

Shared Ryzen 9 5900X (12 cores/24 threads), 46.9 GiB RAM, Samsung 870 EVO SSD, Fedora 44, Docker 29.9.3, Temurin 17.0.20.1. Give the benchmark four distinct cores, 6 GiB RAM, no swap and `-Xms256m -Xmx2g -XX:ActiveProcessorCount=4`; launch `org.languagetool.server.HTTPServer` from the server JAR. Use five check workers, cached pipelines, no result cache or prewarm. Time Docker launch through `/v2/languages`, then the **first actual English POST**, then warm checks. Per cell: five fresh processes; one or five simultaneous first requests; on one JVM discard five additional batches and measure 40 warm requests. Measure through reading the response; verify version, 200 and complete results. Percentiles use nearest rank; five serial cold observations make p95 the maximum. Process-cold excludes pulling the image, fetching the model or flushing OS caches. Desktop contention, bounded vocabulary and short runs limit extrapolation.

## Grove must own the rules, the offsets and the privacy promise

**Verified `/v2/check`.** In 44 main and 11 follow-up synthetic probes, OSS 6.8 reported `apiVersion:1,premium:false`. POST URL-encoded `language=en-US` and exactly one of `text` or `data`; `data` is a form field containing JSON text/markup annotations, not a JSON request body. Bare `en` missed a dictionary typo. Response: software/language metadata, `matches[]` with document `offset,length`, message, `rule.id/subId/category/issueType`, replacements, sentence and context (context offsets are relative). Empty replacements mean explanation only; a replacement whose value is empty means delete. Observe `warnings.incompleteResults`. Emoji occupies two UTF-16 units, NFD combining marks one extra; do not normalize. Annotation `interpretAs` can supply a space, but offsets refer to concatenated original markup+text: `sen<b>tenc</b>` produced a match spanning `sen<b>tenc`. Context can echo hidden markup. Never submit secrets as annotations ([API schema](https://languagetool.org/http-api/languagetool-swagger.json); [6.8 parser](https://github.com/languagetool-org/languagetool/blob/v6.8/languagetool-server/src/main/java/org/languagetool/server/ApiV2.java)).

Use `level=default`, `enabledOnly=true` and **one CSV of rule IDs**. Normal enabled/disabled rules/categories adjust defaults. With `enabledOnly`, mixing category and rule enables did **not** produce a union; empty-only or mixing disabled lists returned 400. Unknown-only ID gave 200/no matches. Picky-only `EN_DASH_RULE` required `level=picky` despite explicit enable. `getAllRules()` on plain `en-US` yielded **6,208 objects, 3,051 distinct IDs, 23 category IDs**, not 3,051 active checks. Match on pinned version/language/ID plus sub-ID and local guard, not `issueType` (`EN_A_VS_AN` reports misspelling). These starter mappings each fired on a local fixture ([selection implementation](https://github.com/languagetool-org/languagetool/blob/v6.8/languagetool-core/src/main/java/org/languagetool/tools/Tools.java); [Grove switch definitions](https://github.com/miniaxolotl/grove/blob/a47f1d443441fdbb06d385f56be601d518add762/lib/shared/src/writing-settings.ts)).

**Category policy:** the table admits individual IDs in eight categories; drop everything else in those eight. Drop all 15 remaining categories: `AMERICAN_ENGLISH_STYLE`, `BRITISH_ENGLISH`, `COLLOCATIONS`, `COMPOUNDING`, `CREATIVE_WRITING`, `MULTITOKEN_SPELLING`, `NONSTANDARD_PHRASES`, `PLAIN_ENGLISH`, `PROPER_NOUNS`, `REPETITIONS_STYLE`, `SEMANTICS`, `STYLE`, `TEXT_ANALYSIS`, `TON_ACADEMIC`, `WIKIPEDIA`. Reject unknown IDs/categories. Global/domain/ancestor `enabled` and eligible-field gates precede reading text. `grammar` gates its ten children independently of `spelling`; skip empty profiles. Map English to `en-US`; `automatic` controls scheduling, `highlights` presentation, `aiRewrites` separate consent/workflow, `words` on-device case-insensitive filtering. None authorizes upload.

**Public, paid and private differ.** The [anonymous endpoint](https://dev.languagetool.org/public-http-api.html) prohibits automated requests; peak 20 requests/IP/min, 75 KB text/IP/min, 20 KB/request, suggestions for 30 misspelled words. Swagger describes character limits (free 75,000/min, 20,000/request; Premium 80 requests/min, 300,000 chars/min, 60,000/request plus plan caps). Do not equate bytes and characters. Self-hosting does not inherit these quotas: a 20,902-character check succeeded; set byte, UTF-16, time, queue and concurrency bounds. OSS had zero premium-marked rules. Neither n-grams, credentials nor `picky` installs private code. [Premium](https://languagetool.org/premium) adds specific advanced comma, agreement, confusion and style checks, not entire categories; no versioned proprietary English ID list. The [paid API](https://languagetool.org/proofreading-api) and [licensed enterprise on-prem](https://forum.languagetool.org/t/does-self-hosting-contain-premium-features/8474) are separate vendor decisions. No public or commercial endpoint was tested.

**Trust boundary:** start with a signed-in first-party editor, manual opt-in disclosing the paragraph, destination and retention. Guest, offline, sensitive fields and third-party extension sites stay local; automatic remote checks would require a separate affirmative setting. Grove [currently promises local proofing](https://github.com/miniaxolotl/grove/blob/a47f1d443441fdbb06d385f56be601d518add762/documentation/webapp-writing.md). Preserve the existing 350 ms local debounce; proposed remote target is ≤1,500 UTF-16 units after 650 ms quiet, manual ceiling 6,000. Skip uncertain markup, IME and overlong spans. A parser-aware mask reduces disclosure but cannot identify secrets in ordinary prose. Web uses authenticated same-origin BFF → Grove API; extension, if approved later, uses its trusted background. Never expose raw LT, select upstream from client input or forward identity headers.

Validate a strict shared schema, origin, current consent and profile before a single bounded synchronous POST. Limit encoded bytes separately, bound streamed response bytes/matches, return revision, ranges, known rule keys and capped replacements only. One in flight per editor; proposed warm dispatch p95 ≤450 ms, client/API/upstream cutoffs 900/700/550 ms. Shed excess immediately, cancel superseded work and bound **aggregate work per JVM across API replicas**. In Go/Rust stub tests both enforced 65,536 wire bytes/6,000 units, shed overload, timed out near 301 ms and did not replay; after disconnect a noncooperative worker still worked ~0.9 s. Real LT cancellation is unverified. Distinguish busy/partial/unavailable from “no findings.” Save and local checks must keep working.

Compare editor identity, revision, policy epoch and exact original/masked slices before decoration and again on apply. Reject hidden, stale, split-grapheme, noncontiguous or empty spans; sort deterministically, preserve meaningful same-span alternatives, local curated fixes, ignore-per-occurrence and undo. Cap at 50 issues/three alternatives and mark truncation. No detached request, durable draft queue, response cache or retry. Whole-document jobs would need a separate contract for already saved authorized revisions; existing [AI jobs](https://github.com/miniaxolotl/grove/blob/a47f1d443441fdbb06d385f56be601d518add762/lib/memory/src/writing-jobs.ts) intentionally persist encrypted inputs and are unsuitable here.

**Logging is the release blocker.** Malformed annotation reflected a synthetic marker in an HTTP 400 even with `inputLogging=no`; source shows exception/span, IP, credential and verbose text paths ([LT error handler](https://github.com/languagetool-org/languagetool/blob/v6.8/languagetool-server/src/main/java/org/languagetool/server/LanguageToolHttpHandler.java)). Discard upstream errors; never log bodies, context, suggestions, validation values, headers, queries or draft hashes. Disable LT IP/debug/DB check/match logging, text caches, raw stdout capture, tracing payloads, replay, swap and dumps. Disable request **and** response disk buffering at BFF, ingress and proxy ([NGINX buffering](https://nginx.org/en/docs/http/ngx_http_proxy_module.html#proxy_request_buffering)); `no-store` alone is insufficient. Monitor only aggregate status, latency buckets, saturation, deadlines, JVM health and version. Test marked synthetic success, malformed, chunked/oversize, timeout, overload, disconnect and 5xx paths; inspect transient writes, logs, traces, backups and managed ingress behavior. Until verified, do not promise zero retention or immediate heap erasure.

## Conclusion

The owner’s first decision is whether a separately consented enhanced grammar profile earns its place beside Grove’s curated spelling. Keep nspell 2.1.5 (MIT) and its [separately licensed SCOWL dictionary](https://unpkg.com/dictionary-en@4.0.0/license) as the comparison baseline; [Harper](https://github.com/Automattic/harper/releases/tag/v3.2.0) is Apache-2.0 and a practical local grammar candidate. [nlprule 0.6.4](https://github.com/bminixhofer/nlprule/blob/0.6.4/README.md) is an older partial LT 5.2 port; [WriteMoreBetter 0.15.2](https://github.com/cmlarsen/writemorebetter/releases/tag/0.15.2) reports 98% of LT 6.6 XML rule examples, not 98% accuracy, lacks LT n-grams and needs its own WASM build. Both have MIT-or-Apache engines with separately LGPL-derived data. [Spellbook](https://github.com/helix-editor/spellbook/releases/tag/v0.4.2) is MPL-2.0 spelling only. [LT is LGPL-2.1-or-later](https://github.com/languagetool-org/languagetool/blob/v6.8/COPYING.txt): private HTTP operation differs from distributing a built image, linked library or client binary. Running a separate private process is compatible with MIT Grove; publishing a Dockerfile that downloads upstream binaries generally distributes the recipe, not those binaries. A published built image distributes its contents. Before redistribution, inventory exact JARs, dictionaries (including GPL German data), transformed [Google Books data](https://books.google.com/ngrams/datasets), notices, corresponding sources and replacement/relink obligations; a Dockerfile or hash does not settle licensing.

Decide pilot surface, false-alarm tolerance, latency/availability budget and privacy evidence **before spending**. Test held-out jargon and homophones, clean-control false alarms, first edits, zero stale or masked edits, and low-end clients. If admitted, keep one Grove release/tag, separate pinned engine/JRE/rule/model manifest, optional self-host Compose profile without published ports, synthetic English readiness and rollback to local-only ([release contract](https://github.com/miniaxolotl/grove/blob/a47f1d443441fdbb06d385f56be601d518add762/documentation/release-conventions.md)). Ramp only consenting, stable cohorts behind a kill switch. Revisit B only on demonstrated incremental model value. **Optional paid trial, requires approval:** six hours, isolated `nyc1` VPC, one Ubuntu 24.04 `s-4vcpu-8gb`, 60 GiB ext4 volume, separate `nyc` sandbox App with a $5/month 512 MiB synthetic worker, no LB/NAT/bucket. Estimated **$0.54** before tax/overage ($59/month if left running). Verify private-only routing and rejection, volume recovery, checksum failure, cold and warm p95, OOM headroom; destroy app, VM **and volume**. No paid step has been taken.
