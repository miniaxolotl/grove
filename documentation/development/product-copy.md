# Product copy

Write for the person using Grove, not the infrastructure running it. Ordinary
workspace, sign-in, marketing and recovery copy describes features and next steps.
Do not name backend companies, model names, hosting platforms or internal jobs.

- Name the feature and match its control: **Read aloud**, **Recording
  transcription**, **AI preferences**, **Transcribe** and **Prepare audio**.
- Explain what a feature does, when it runs and what the person can review.
  Keep speech opt-ins independent and explicit. Preparing audio uses saved note
  text; transcription processes a recording only after **Transcribe**. Neither
  opening the controls nor enabling a preference starts that work.
- Use availability language, not configuration diagnoses: “Read aloud is currently
  unavailable.” Do not tell an ordinary user to configure an installation/server.
- Keep privacy information meaningful. Describe external recipient categories,
  the information sent, controls, retention and the limits of cancellation. Do not
  imply local-only processing or that disabling a feature recalls transmitted data.
- Keep necessary names in operator/self-host instructions and editable service
  configuration. Preserve user-chosen connected-account identities, agent names
  needed to install integrations, and attribution/links for external sources.
  Required legal attribution must remain accurate.

## Examples

| Avoid                                                      | Prefer                                            |
| ---------------------------------------------------------- | ------------------------------------------------- |
| Turn this on to send audio or note text to a named vendor. | Turn on Read aloud in AI preferences.             |
| Speech isn’t configured for this installation.             | Recording transcription is currently unavailable. |
| Public sharing is not configured on this server.           | Public sharing is currently unavailable.          |
| Sign-in is awaiting authentication-provider configuration. | Sign-in is unavailable. Please try again later.   |

Inline settings links stay underlined so colour is not their only distinguishing
feature. Review wrapping, navigation and accessibility at desktop, 390px and 320px.
Use synthetic notes/recordings for captures, never personal content.
