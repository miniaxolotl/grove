# Marketing-kit photograph

`grove-journal.webp` is a locally served WebP derivative of the kit's
`marketing/_source/assets/photos/grove-journal.jpg`, by Jessica Mangano under the
[Unsplash licence](https://unsplash.com/license). It is editorial photography,
not a Grove user's note or endorsement. `manifest.json` records source/output
hashes, dimensions and the original image URL. The kit is unchanged.
