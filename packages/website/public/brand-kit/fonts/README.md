# Font assets

The existing WOFF2 files serve the website. `jetbrains-mono-regular.ttf` is the
unmodified JetBrains Mono **2.304** Regular face used for PDF code blocks and inline
code; it is fetched only when the export contains code and embedded as a subset.

Source: <https://github.com/JetBrains/JetBrainsMono/blob/v2.304/fonts/ttf/JetBrainsMono-Regular.ttf>
