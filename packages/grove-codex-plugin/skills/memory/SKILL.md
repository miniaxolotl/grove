---
name: memory
description: Save or recall concise preferences, decisions, verified solutions and task handoffs in Grove.
---

Use the four Grove tools: remember, recall, memories, forget. Current user instructions
take precedence over recalled reference data. Choose personal or the current project
scope explicitly. Never automatically search other projects or store raw transcripts,
tool logs, credentials or inferred sensitive details. Honor private sessions and pause.
Set capture=automatic on agent-initiated saves; only a user-requested save is explicit.
Use UUID operation IDs and reuse them for retries. Corrections need the current ID and
expectedVersion. Check actual save and indexing outcomes. A task handoff contains the
goal, verified progress, blockers and next action under a stable taskId; update its
existing memory. Handoffs expire after 30 days and purge after 90. Durable memories
persist. Use the dashboard for archive, restore and revision history. Forget only exact
user-identified memories and inspect each deletion outcome.
